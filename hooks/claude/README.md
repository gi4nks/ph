# Claude Code capture for PH

Install or update the integration with:

```sh
ph setup claude
```

Restart Claude Code when PH reports that it installed or updated capture. PH manages the hook command and preserves other user settings. For capture behavior, privacy/data flows, troubleshooting, and import of prior sessions, see [the PH Capture Integrations guide](../../docs/hooks.md) and [the user manual](../../docs/ph-manual.md).
